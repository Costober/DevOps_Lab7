# Лабораторна робота №5: Створення простого API
**Автор:** Кузьменко Костянтин, група АІ-233

## Опис
Цей сервіс надає HTTP API для обчислення коренів рівняння (метод хорд) та розв'язання СЛАР (метод Якобі).

## Запуск
1. Встановіть залежності: `pip install -r requirements.txt`
2. Запустіть сервер: `python app.py`

## Приклади запитів
- **Метод хорд:** `GET /calculate?method=secant&x0=-5&x1=0`
- **Метод Якобі:** `GET /calculate?method=jacobi`
